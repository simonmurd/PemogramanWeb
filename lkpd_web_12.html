2 Ringkasan Teori: Manipulasi Document Object Model (DOM) dengan JavaScript

Bab 12: DOM Manipulation

Document Object Model (DOM) adalah antarmuka pemrograman yang merepresentasikan dokumen HTML sebagai sebuah pohon objek (object tree). Dengan JavaScript, kita dapat secara dinamis mengakses, mengubah gaya (CSS), memperbarui teks, serta merubah struktur elemen HTML berdasarkan interaksi pengguna (event handling).

1. Seleksi Elemen DOM

Mengambil elemen HTML dari dokumen menggunakan CSS Selector modern.

// Seleksi satu elemen pertama
const btn = document.querySelector('#btn-theme');
// Seleksi banyak elemen (NodeList)
const items = document.querySelectorAll('.list-item');

2. Manipulasi Style & Class List

Mengubah class CSS atau style inline elemen secara instan.

// Toggle class CSS (Light/Dark)
card.classList.toggle('dark-theme');
// Ubah properti CSS langsung
text.style.fontSize = '18px';

3. Membuat & Menghapus Elemen

Menambahkan elemen baru ke DOM atau menghapusnya secara permanen.

const newLi = document.createElement('li');
newLi.textContent = 'Tugas Baru';
listParent.appendChild(newLi);
newLi.remove(); // Menghapus elemen

4. Event Handling

Mendengarkan dan merespon tindakan user (klik, ketikan, perubahan input).

button.addEventListener('click', (event) => {
  console.log('Tombol diklik!');
});
