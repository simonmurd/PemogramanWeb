2 Ringkasan Teori: Format Multimedia pada HTML

Dasar Web

Tampilan halaman web yang hanya berisi teks akan terasa membosankan. Oleh karena itu, HTML menyediakan tag khusus untuk menyisipkan media seperti Gambar, Audio, dan Video untuk membuat halaman web lebih interaktif dan menarik bagi pengguna.

Komponen Multimedia HTML5
Jenis Media Tag HTML Format File yang Didukung
Gambar Visual <img src="..."> .jpg, .png (Transparan), .svg (Vektor), .webp
Suara / Audio <audio controls> .mp3 (Terpopuler), .wav, .ogg
Video Bergerak <video controls> .mp4 (Terpopuler), .webm, .ogg
Embed Eksternal <iframe src="..."> Link YouTube, Google Maps, dll.

Atribut Wajib Gambar

Gunakan atribut src untuk sumber file dan alt (teks alternatif) untuk aksesibilitas dan antisipasi jika gambar gagal dimuat.

Atribut Kontrol Media

Tambahkan atribut controls pada tag audio/video agar memunculkan tombol Play, Pause, dan Volume bawaan browser.

Teks Fallback

Sertakan teks peringatan di antara tag pembuka & penutup <video>...</video> apabila browser pengguna terlalu lawas.
