2 Ringkasan Teori: Client-Side vs Server-Side Scripting

Dasar Pemrograman Web

Dalam ekosistem pengembangan web modern, logika pemrograman dibagi menjadi dua wilayah utama: Client-Side (berjalan di sisi pengguna/browser) dan Server-Side (berjalan di sisi server pusat). Pembagian ini penting untuk mengoptimalkan kecepatan, keamanan, dan pengalaman pengguna (seperti zero page refresh).

Perbandingan Eksekusi Scripting
Aspek Client-Side Scripting Server-Side Scripting
Tempat Eksekusi Web Browser pengguna (Chrome, Firefox, dll). Mesin Web Server (Apache, Nginx, Node.js).
Bahasa Populer JavaScript (JS), TypeScript, HTML, CSS PHP, Python, Ruby, Java, C#, Node.js
Fokus Utama Interaktivitas UI, validasi form instan, animasi, manipulasi DOM (Dokumen). Keamanan data, autentikasi login, query database, pemrosesan bisnis logika berat.
Visibilitas Kode Bisa dilihat oleh user (Inspect Element). Tersembunyi dari user, aman dari akses publik.

Zero Page Refresh (Client-Side)

JavaScript memungkinkan web memperbarui tampilan tanpa memuat ulang seluruh halaman (reload). Contoh: Menekan "Like" di Instagram, validasi input salah, atau memuat pesan baru.

Autentikasi Data (Server-Side)

Validasi yang bersifat krusial dan rahasia (seperti mencocokkan password atau memproses saldo bank) wajib dilakukan di server, karena kode Client-Side bisa dimanipulasi pengguna.
