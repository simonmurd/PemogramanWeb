2 Ringkasan Teori: Anatomi & Elemen Form HTML

HTML5 Standards

Formulir (Form) pada halaman web digunakan untuk mengumpulkan data dari pengguna (seperti pendaftaran, login, dan survei) agar dapat diproses oleh server. Form dibungkus menggunakan tag <form> dan berisi berbagai elemen interaktif.

Ringkasan Tag & Elemen Form
Elemen / Tag Fungsi Utama Contoh Kode Atribut Penting
<form> Membungkus seluruh elemen input. <form action="proses.php" method="POST"> action (tujuan), method (GET/POST)
<input> Menerima data (teks, sandi, pilihan). <input type="text" name="username"> type (text, password, radio, dll), name
<select> & <option> Membuat menu *dropdown* (pilihan tarik-turun). <select><option>Pilih</option></select> name (pada select), value (pada option)
<textarea> Menerima input teks panjang / multibaris (pesan/alamat). <textarea rows="4" cols="50"></textarea> rows, cols, placeholder

Atribut Placeholder

Teks bayangan abu-abu di dalam input sebagai petunjuk pengisian sementara.

Atribut Required

Memaksa pengguna untuk mengisi *field* tersebut (tidak boleh dikosongkan sebelum submit).

Atribut Name & Value

name untuk identitas variabel data, value untuk nilai yang akan dikirim ke server.
