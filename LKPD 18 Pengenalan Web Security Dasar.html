2 Ringkasan Teori: Web Security Dasar & Best Practices

Bab 18

Keamanan Web (Web Security) adalah praktik untuk melindungi aplikasi web dari berbagai ancaman, serangan peretasan, dan akses tidak sah. Penerapan kaidah keamanan dasar sangat krusial guna menjaga kerahasiaan (*confidentiality*), integritas (*integrity*), dan ketersediaan (*availability*) data pengguna.

Cross-Site Scripting (XSS)

Serangan di mana peretas menyisipkan kode skrip jahat (seperti JavaScript) pada input aplikasi web. Kode tersebut dapat tereksekusi pada browser pengguna lain untuk mencuri cookie atau session token.

SQL Injection (SQLi) Dasar

Celah keamanan di mana peretas memanipulasi parameter query SQL backend untuk membobol autentikasi login atau membaca/menghapus data sensitif secara ilegal.

HTTPS & SSL/TLS

Protokol komunikasi terenkripsi yang melindungi lalu lintas data antara browser client dan server dari penyadapan (*eavesdropping*) serta serangan Man-in-the-Middle (MitM).

Input Sanitization & Cookie Security

Mengubah karakter khusus ke HTML Entities (`<`, `>`) dan mengamankan cookie menggunakan atribut HttpOnly (mencegah XSS) serta Secure (khusus HTTPS).
