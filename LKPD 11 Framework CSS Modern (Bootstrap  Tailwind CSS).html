2 Ringkasan Teori: Framework CSS Modern (Bootstrap & Tailwind CSS)

Bab 11: Framework CSS

Framework CSS menyediakan kumpulan komponen antarmuka antardepan (UI) siap pakai dan sistem utilitas tata letak responsif. Menggunakan framework seperti Bootstrap atau Tailwind CSS memungkinkan pengembang melakukan rapid prototyping (pembuatan prototipe antarmuka secara cepat, rapi, dan konsisten) tanpa harus menuliskan CSS dari awal.

Sistem Grid 12-Kolom

Layar dibagi menjadi 12 kolom horizontal fleksibel. Kombinasi kolom menentukan lebar elemen.

<!-- Bootstrap: 3 Kolom (12/3 = 4) -->
<div class="col-md-4">Widget</div>
<!-- Tailwind: Grid 3 Kolom -->
<div class="grid grid-cols-1 md:grid-cols-3">

Utility Class (Pendekatan Utilitas)

Kelas pembantu cepat untuk margin (m-2), padding (p-4), warna (bg-blue-500), dan flexbox.

<div class="flex items-center p-4 bg-slate-100 rounded-xl shadow-md">
  <span class="text-sm font-bold text-slate-800">Card</span>
</div>

Breakpoints Responsif

Aturan titik henti responsif (sm, md, lg, xl) menyesuaikan tampilan antarperangkat.

sm: ≥ 640px (Mobile HP)
md: ≥ 768px (Tablet)
lg: ≥ 1024px (Desktop Laptop)

Data Attributes & Komponen Bawaan

Komponen seperti Navbar & Modal menggunakan atribut data bawaan framework untuk interaktivitas tanpa skrip JS murni.

<button data-bs-toggle="modal"
        data-bs-target="#myModal">
  Buka Modal Dialog
</button>
