2 Ringkasan Teori: Arsitektur Client-Server & Ekosistem Web

Dasar Web

Aplikasi Web beroperasi menggunakan model Client-Server Architecture. Klien (seperti Web Browser) mengirimkan *HTTP Request* kepada Web Server. Server kemudian memproses permintaan tersebut dan mengembalikan *HTTP Response* berupa kode status dan resource (HTML, CSS, JS, Gambar, dll).

Komponen Utama Web
Komponen Contoh Software / Teknologi Fungsi Utama
Web Client (Browser) Chrome, Firefox, Safari Menerjemahkan kode HTML/CSS/JS menjadi antarmuka visual yang dipahami manusia.
Web Server Apache, Nginx, LiteSpeed Menyimpan file web dan melayani HTTP Request dari browser klien secara nonstop.
Bahasa Pemrograman (Back-end) PHP, Python, Node.js, Java Menangani logika bisnis, keamanan, dan berinteraksi dengan database (MySQL, PostgreSQL).

Status 2xx (Success)

Contoh: 200 OK. Menandakan bahwa request dari client berhasil diterima, dipahami, dan diproses oleh server.

Status 4xx (Client Error)

Contoh: 404 Not Found. Terjadi kesalahan di sisi klien, misalnya meminta URL atau file yang tidak ada di server.

Status 5xx (Server Error)

Contoh: 500 Internal Server Error. Klien mengirim request benar, namun terjadi masalah pada kode server/database.
