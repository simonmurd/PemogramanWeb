2 Ringkasan Teori: Anatomi dan Cara Kerja CSS

Web Styling

CSS (Cascading Style Sheets) adalah bahasa desain yang digunakan untuk memisahkan konten (HTML) dengan tampilan visual (gaya/style). CSS berfungsi mengatur tata letak, warna, ukuran, serta gaya halaman web agar kodenya lebih terstruktur dan efisien.

Jenis-jenis Penempatan & Selector CSS
Konsep Format Penulisan / Kode Deskripsi / Fungsi
Inline CSS <div style="color: blue;"> Disisipkan langsung ke dalam tag HTML.
Class Selector .nama-class { ... } Digunakan berulang untuk banyak elemen (menggunakan titik).
ID Selector #header-utama { ... } Unik, hanya digunakan satu kali per halaman (menggunakan #).
Pseudo-class .btn:hover { ... } Mengubah gaya saat ada interaksi user (misal: kursor menyentuh).

CSS Box Model

Setiap elemen di web adalah kotak. Terdiri dari Margin (jarak luar), Border (bingkai), Padding (jarak dalam), dan Content (isi elemen).

External CSS

Menyimpan CSS di file terpisah (.css) dan dipanggil menggunakan tag <link rel="stylesheet">. Cara paling direkomendasikan dan efisien.

Anatomi CSS

Terdiri dari Selector (elemen yang dipilih), Property (apa yang diubah), dan Value (nilainya). Contoh: h1 { color: red; }
