2 Ringkasan Teori: Pembuatan Aplikasi Web Portofolio Interaktif

Bab 20

Proyek akhir web merupakan puncak integrasi dari seluruh kompetensi pengembangan web frontend. Aplikasi web utuh menggabungkan HTML5 Semantik untuk struktur, CSS3 Responsif untuk gaya visual, JavaScript DOM & API untuk interaktivitas dinamis, penyimpanan lokal (localStorage), serta alur kerja publikasi (deployment) ke web server publik.

Sprint Planning & Integrasi DOM

Merencanakan fitur aplikasi web (To-Do List, Weather Dashboard, atau Katalog Produk), memetakan elemen HTML, serta memanipulasi elemen DOM secara interaktif menggunakan JavaScript.

Fetch API & LocalStorage

Mengambil data dinamis dari server eksternal melalui fetch() API dan menyimpan state aplikasi pengguna di browser menggunakan API localStorage.

Portfolio Launch & Hosting

Mempublikasikan kode program ke platform web hosting publik seperti GitHub Pages, Netlify, atau Vercel agar dapat diakses oleh publik secara real-time.

Peer Review & Uji UX

Melakukan pengujian keterpakaian aplikasi antarteman untuk mengukur kenyamanan pengguna (User Experience), responsivitas desain, serta performa aplikasi.
