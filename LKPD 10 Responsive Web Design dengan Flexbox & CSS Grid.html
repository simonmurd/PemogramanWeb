2 Ringkasan Teori: Desain Web Modern

Bab 10: RWD

Responsive Web Design (RWD) memastikan antarmuka web beradaptasi secara optimal pada berbagai ukuran layar (HP, Tablet, Desktop). Pendekatan ini diwujudkan melalui teknik layouting modern seperti Flexbox dan CSS Grid, serta penggunaan Media Queries dengan prinsip Mobile-First Design.

Flexbox (Layout 1 Dimensi)

Ideal untuk menata elemen dalam satu baris (baris saja atau kolom saja). Mengatur ruang dan penyejajaran elemen secara dinamis.

display: flex;
flex-wrap: wrap;
justify-content: space-between;

CSS Grid (Layout 2 Dimensi)

Dirancang untuk struktur kompleks yang melibatkan baris sekaligus kolom. Sangat handal untuk layout galeri atau halaman utama.

display: grid;
grid-template-columns: repeat(auto-fit, minmax(200px, 1fr));

Media Queries & Breakpoints

Aturan CSS yang hanya aktif jika resolusi perangkat memenuhi syarat tertentu (misal: layar lebih lebar dari 768px).

@media (min-width: 768px) {
  .menu-mobile { display: none; }
}

Mobile-First Design

Prinsip merancang antarmuka untuk layar terkecil (HP) terlebih dahulu, lalu diperluas (scale-up) ke layar besar dengan Media Queries.

/* CSS Default: HP */
/* CSS @media min-width: Desktop */
