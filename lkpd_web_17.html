2 Ringkasan Teori: Pengenalan Server Side Scripting & Database Dasar

Bab 17

Server-side scripting adalah teknik pemrograman web di mana skrip dieksekusi di sisi server web, sebelum hasilnya (berupa HTML) dikirimkan ke web browser pengguna (client). Hal ini berbeda dengan client-side scripting (seperti JavaScript murni di browser) yang dieksekusi langsung di perangkat pengguna.

Arsitektur Client-Server

Client (browser) mengirimkan Request (permintaan) melalui metode GET/POST. Server memproses permintaan tersebut dan mengirimkan Response (tanggapan) kembali ke client.

PHP & Node.js

PHP adalah bahasa scripting sisi server paling populer. Node.js memungkinkan eksekusi JavaScript di sisi server. Keduanya bertugas mengolah logika bisnis dan menghubungkan aplikasi dengan database.

Database (Basis Data)

Tempat penyimpanan data secara terstruktur. Terdapat tipe Relasional (SQL) seperti MySQL/PostgreSQL dan Non-Relasional (NoSQL) seperti MongoDB.

Konsep CRUD

Operasi dasar mengelola data: Create (Menambah data), Read (Membaca/menampilkan data), Update (Memperbarui data), dan Delete (Menghapus data).
