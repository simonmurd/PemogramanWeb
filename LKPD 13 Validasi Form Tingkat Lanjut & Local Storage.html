2 Ringkasan Teori: Validasi Form Tingkat Lanjut & Web Storage API

Bab 13: Form & Storage

Pengolahan data formulir di sisi klien memerlukan tingkat keandalan yang tinggi. Penggunaan Regular Expression (RegEx) memungkinkan pemfilteran format email dan kriteria password secara real-time. Sementara itu, Web Storage API (localStorage & sessionStorage) berguna untuk menyimpan preferensi pengguna atau draf formulir secara langsung pada peramban web tanpa memerlukan basis data eksternal.

1. Regular Expression (RegEx)

Pola untuk mencocokkan kombinasi karakter pada string (misal: validasi email/password).

const emailRegex = /^[^\s@]+@[^\s@]+\.[^\s@]+$/;
const isValid = emailRegex.test(emailInput.value);

2. Local Storage API

Menyimpan data tanpa batas waktu (persisten), tetap ada meski tab/browser ditutup.

localStorage.setItem('username', 'Budi');
const name = localStorage.getItem('username');
localStorage.removeItem('username');

3. Session Storage API

Menyimpan data sementara untuk sesi tab saat ini. Data terhapus saat tab ditutup.

sessionStorage.setItem('tempDraft', 'Isi Form');
const draft = sessionStorage.getItem('tempDraft');

4. Event Real-time Form

Merespons ketikan pengguna secara langsung tanpa menunggu tombol submit diklik.

input.addEventListener('input', (e) => { ... });
input.addEventListener('blur', (e) => { ... });
