2 Ringkasan Teori: Hosting, Domain, dan Deployment Halaman Web

Bab 16: Deployment & Performance

Peluncuran Situs Web (Deployment) adalah proses mentransfer proyek berkas statis (HTML, CSS, JS) dari komputer lokal ke server publik agar dapat diakses pengguna di seluruh dunia. Konsep utama mencakup Web Hosting (ruang penyimpanan berkas di server), Domain Name System (DNS) (pengalamatan teks seperti sekolah.sch.id), alur integrasi CI/CD otomatis via platform modern (GitHub Pages, Vercel, Netlify), serta pengujian kualitas situs web melalui pengujian performa (Google Lighthouse Audit) dan keterbacaan di berbagai browser (*cross-browser testing*).

Domain & Web Hosting

Web Hosting menyimpan aset situs web, sedangkan DNS memetakan alamat IP server yang rumit menjadi nama domain human-readable (TLD: .com, .id, .net).

Domain: www.proyek-siswa.com
IP Server: 76.76.21.21
DNS Record: A Record -> IP Hosting

Automated Deployment (CI/CD)

Platform Cloud modern terhubung langsung ke repositori Git. Setiap pembaruan kode yang di-push akan di-build dan di-deploy secara publik secara otomatis.

Git Commit & Push -> Webhook Trigger
Automated Build -> Production URL
Active Live SSL/HTTPS

Audit Performa Google Lighthouse

Perkakas Chrome DevTools untuk mengukur 4 pilar utama situs web: Performance, Accessibility, Best Practices, dan SEO.

- Performance: FCP, LCP, CLS
- Accessibility: Alt Text, Color Contrast
- SEO: Meta Description, Title Tag

Optimasi Kode & Cross-Browser

Meningkatkan kecepatan web melalui minifikasi berkas CSS/JS, kompresi format gambar WebP, dan pengujian konsistensi lintas peramban web.

1. Kompresi Gambar: JPG/PNG -> WebP
2. Minify CSS/JS: Hapus whitespace
3. Responsive View: Viewport Test
