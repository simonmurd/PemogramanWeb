2 Ringkasan Teori: Asynchronous JavaScript & Fetch API

Bab 14: Async & Fetch

Asynchronous Programming memungkinkan JavaScript menjalankan proses asynchronous (seperti mengambil data dari server eksternal) di latar belakang tanpa menghentikan (blocking) eksekusi kode lainnya. Kombinasi Promise, sintaks async/await, format JSON, dan API bawaan fetch() memungkinkan aplikasi web mengambil dan menampilkan data dinamis secara instan tanpa perlu memuat ulang (*reload*) halaman.

Konsep Synchronous vs Asynchronous

Synchronous mengeksekusi kode berurutan baris demi baris (blocking). Asynchronous mengeksekusi proses lambat secara non-blocking di latar belakang.

console.log("Awal");
setTimeout(() => console.log("Async Process"), 1000);
console.log("Akhir"); // Dieksekusi sebelum setTimeout

Sintaks Async / Await & Promise

async menandakan fungsi mengembalikan Promise. await menunda eksekusi sampai Promise selesai (settled).

async function getData() {
  const res = await fetch(url);
  const data = await res.json();
}

Format Data JSON

JavaScript Object Notation: Format standar pertukaran data. Diubah dengan JSON.parse() dan JSON.stringify().

{"nama": "Siswa", "kelas": "XI TJKT", "aktif": true}

Loading State & Error Handling

Gunakan indikator pemrosesan (spinner) dan blok try...catch...finally untuk menangani error jaringan atau HTTP status 404/500.

try {
  if (!res.ok) throw new Error("Gagal mengambil data");
} catch (err) { alert(err.message); }
