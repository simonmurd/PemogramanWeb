2 Ringkasan Teori: Analisis UX/UI dan Wireframing

Bab 19

Kompetensi Dasar (KD): Menerapkan prinsip User Experience (UX) dan User Interface (UI) dalam merancang tata letak web sebelum masuk ke tahap koding, menggunakan alat desain, menetapkan konsistensi, serta mengaudit aksesibilitas.

UX & UI Konsep

UX (User Experience) berfokus pada alur fungsional, kemudahan, dan pengalaman pengguna. UI (User Interface) berfokus pada visual, warna, dan tipografi antarmuka agar terlihat menarik dan konsisten.

Low-Fidelity Wireframing

Merupakan sketsa kasar untuk menentukan hirarki informasi, posisi navigasi, dan CTA (Call-to-Action) menggunakan aplikasi desain seperti Figma atau Canva sebelum dilakukannya prototyping dan coding.

Design System & Tipografi

Menyusun panduan gaya (Style Guide) yang mencakup konsistensi font, margin, hirarki ukuran teks (H1, H2, p), dan palet warna brand agar antarmuka web tetap terstruktur rapi.

Web Accessibility (a11y)

Standar WCAG (Web Content Accessibility Guidelines) memastikan web dapat diakses oleh semua orang, termasuk pengujian rasio kontras (Contrast Checker) keterbacaan teks di atas warna latar belakang.
