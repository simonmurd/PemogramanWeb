2 Ringkasan Teori: Dasar Pemrograman JavaScript

Bab 9: Web Interaktif

JavaScript (JS) adalah bahasa pemrograman yang membuat website menjadi hidup dan interaktif. Dengan JS, halaman web tidak lagi statis, melainkan dapat merespon klik (Event Handler), melakukan perhitungan matematika otomatis (Operator), hingga mengubah tampilan seketika (DOM Manipulation).

Variabel & Tipe Data

Variabel digunakan untuk menyimpan data. Dalam JS modern kita menggunakan let (bisa diubah) atau const (tetap).

let harga = 10000; // Tipe: Number
let nama = "Budi"; // Tipe: String

Operator Matematika

Digunakan untuk kalkulasi: + (tambah), - (kurang), * (kali), / (bagi).

let diskon = 20 / 100;
let total = harga - (harga * diskon);

Percabangan (If/Switch)

Membuat keputusan logika berdasarkan kondisi tertentu.

if (nama == "") {
  alert("Nama tidak boleh kosong!");
}

Event Handler & Fungsi

Fungsi (kumpulan kode) yang dipicu saat terjadi interaksi (Event) seperti tombol diklik (onclick).

function sapa() { alert("Halo!"); }
<button onclick="sapa()">Klik</button>
